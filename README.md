# GAMEKEY MARKET

Prototipo de tienda digital de videojuegos construido con Next.js 14.

## Funciones incluidas
- Landing page responsive.
- Catálogo con búsqueda y filtros.
- Fichas de producto y selector de plataforma/edición.
- Carrito de demostración.
- Checkout simulado sin cobros ni datos de tarjeta.
- Vista de pedidos de prueba.
- Panel de demostración.

## Desarrollo
```bash
npm install
npm run dev
```

## Despliegue
Importa este repositorio en Vercel. Framework: Next.js. Build: `npm run build`.

## Importante
Los productos y precios son datos de muestra. No existe inventario, licencia, código de activación, pasarela de pago ni entrega digital real. Antes de vender, integra proveedores autorizados, verificación de derechos de reventa, pagos seguros, inventario y políticas de reembolso. GAMEKEY MARKET es una marca conceptual independiente y no está afiliada a Rockstar Games.
